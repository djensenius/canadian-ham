# French interface style

French UI copy follows Canadian federal (Translation Bureau) typography and terminology. Official ISED/ISDE question-bank text remains verbatim; these rules apply to original interface copy only.

## Typography

- Use a no-break space (U+00A0) before `:` and `%` in French UI copy.
- Use a no-break space inside French guillemets: `« terme »`.
- Do not add a space before `;`, `?`, or `!`.
- Keep attribution, disclaimer, and other legal-review footer text in English in the French UI, tagged with `lang="en"`, until the T-606 owner/legal review approves localized legal copy.

# fixtures/engine

Purpose: language-neutral quiz, exam, scoring, readiness, and spaced-repetition fixtures.

Belongs here:

- JSON inputs and expected outputs consumed by both TypeScript and Swift engines.
- Deterministic RNG, exam-generation, scoring, weak-area, readiness, and Leitner fixtures.

Must not go here:

- Engine implementation code.
- UI snapshots or localized copy assertions.
- Verbatim ISED source files.

Relevant docs: [`../../docs/architecture.md`](../../docs/architecture.md), [`../../docs/requirements.md`](../../docs/requirements.md).

Fixture JSON format is documented in [`../README.md`](../README.md). Reference outputs are generated by:

```sh
node packages/engine-ts/src/generate-fixtures.ts
```

Drift check:

```sh
node packages/engine-ts/src/generate-fixtures.ts --check
```

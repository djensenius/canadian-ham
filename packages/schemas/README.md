# packages/schemas

Purpose: schema definitions for content, generated bank records, progress records, and fixtures.

Belongs here:

- JSON Schema or TypeScript schema definitions once T-003 is implemented.
- Schema tests and examples that do not duplicate official source artifacts.

Must not go here:

- Generated bank JSON.
- App UI code.
- Verbatim ISED source files.

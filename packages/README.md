# packages

Purpose: shared tooling, schemas, and engines used by web, Apple, and content workflows.

Belongs here:

- TypeScript content tooling under [`content-tools/`](content-tools/).
- TypeScript engine implementation under [`engine-ts/`](engine-ts/).
- Swift engine package under [`engine-swift/`](engine-swift/).
- Shared schema definitions under [`schemas/`](schemas/).

Must not go here:

- App-specific UI code.
- Verbatim ISED source artifacts.
- Generated normalized JSON output.

Relevant docs: [`../docs/architecture.md`](../docs/architecture.md), [`../docs/requirements.md`](../docs/requirements.md), [`../docs/privacy.md`](../docs/privacy.md).

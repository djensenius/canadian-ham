# App icon system

The Canadian Ham icon follows the owner's app family: a single sumi-e-inspired ink mark on a warm cream field with generous breathing room. The motif is a hand-brushed antenna mast with three tapered radio arcs. The owner may replace this programmer-authored SVG with handmade artwork later; the layer contract and export sizes should remain stable.

## Source layers

All primary SVG sources use a shared `0 0 1024 1024` coordinate system:

- `src/background.svg`: opaque warm cream field with only a very subtle radial warmth; no ruled or tiled grain.
- `src/waves.svg`: middle transparent layer with deterministic variable-width filled radio arcs.
- `src/mast.svg`: front transparent layer with the tapered mast.
- `src/seal.svg`: intentionally empty transparent layer. A vermilion maple seal was tested and dropped because it became a distracting red speck at 60 px.
- `src/landscape.svg`: wide transparent Top Shelf composition with a light centred base, mast, and drifting arcs.

The brush silhouettes are generated by `render.swift`: it samples centreline curves, offsets both sides by low-frequency deterministic width profiles, and keeps dry-brush roughness to the tail ends. The generated SVGs are committed so artwork can be reviewed without running the renderer.

## Iteration notes

The icon redo was compared against `/tmp/ch-reviews/style-reference.png` during five render/read passes:

1. **Pass 1:** Replaced the marker-line antenna with computed filled brush paths. Critique: the mast/arcs were readable and tapered, but the first roughness values made the edges too saw-toothed and the maple seal read as a red fleck at 60 px.
2. **Pass 2:** Lowered edge roughness, increased curve samples, and removed the seal layer. Critique: the mark fit the FluxHaus/Rhizome cream-and-ink family better, but the visual centre leaned too far right.
3. **Pass 3:** Shifted the mast and arcs left so the full mark centres in the tile while still filling roughly 55-65% of the canvas. Critique: 60 px readability was good, but the innermost arc still made the mark feel a little too much like a generic Wi-Fi glyph.
4. **Pass 4:** Shortened and thinned the inner arc, keeping three radio arcs while making the overall gesture looser and less mechanical.
5. **Pass 5:** Moved the radio arcs to radiate from the mast tip, dropped the icon ground stroke, smoothed body edges, and limited dry-brush detail to the tails. Current critique: the icon reads as a radio antenna at 60 px and 120 px, keeps pure black ink on warm cream, avoids background grain, and sits closer to the owner's one-gesture app family.

## Re-rendering

From the repository root:

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift design/app-icon/render.swift
```

The script is zero-dependency Swift using AppKit `NSImage` SVG rendering on macOS. It rewrites the SVG sources and PNG exports deterministically from fixed seeds.

## Exports

Exports are written to `design/app-icon/exports/`.

### iOS, iPadOS, macOS

- `app-icon-1024.png`: flattened opaque 1024 x 1024 PNG; no alpha and no pre-rounded corners.
- `app-icon-60.png` and `app-icon-120.png`: review renders included on the preview sheet to check small-size legibility.

### visionOS Solid Image Stack

- `visionos-back-1024.png`: opaque cream back layer.
- `visionos-middle-1024.png`: transparent waves layer.
- `visionos-front-1024.png`: transparent mast layer.

Key content stays inside the central safe circle for visionOS masking.

### tvOS layered app icon

For each stack, the `back` layer is opaque and the `middle`/`front` layers are transparent:

- Small icon @1x: `tvos-small-400x240-{back,middle,front}.png`.
- Small icon @2x: `tvos-small-800x480-{back,middle,front}.png`.
- App Store icon: `tvos-app-store-1280x768-{back,middle,front}.png`.

Top Shelf images:

- `tvos-top-shelf-1920x720.png` and `tvos-top-shelf-3840x1440.png`.
- `tvos-top-shelf-wide-2320x720.png` and `tvos-top-shelf-wide-4640x1440.png`.

The Top Shelf formats place the brush landscape on the left third with generous cream space and a large serif “Canadian Ham” title on the right, without overlapping the artwork.

### Web

- `favicon.svg`: simplified bold mast/arcs version with separated strokes and a dark-mode variant through `prefers-color-scheme`.
- `favicon-16.png`, `favicon-32.png`, and `favicon-64.png`: light-mode review renders included on the preview sheet.
- `apple-touch-icon-180.png`.
- `pwa-icon-192.png` and `pwa-icon-512.png`.

### Preview

- `preview-sheet.png`: contact sheet showing the main platform exports together for review, including 60 px and 120 px app-icon renders plus 16 px, 32 px, and 64 px favicon renders.

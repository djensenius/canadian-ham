# apps

Purpose: platform application shells live here.

Belongs here:

- `web/` for the static Vite + React + TypeScript web app.
- `apple/` for the SwiftUI multiplatform Apple app.

Must not go here:

- Verbatim ISED source files; use [`../content/sources/ised/`](../content/sources/ised/).
- Shared engines, schemas, or content tooling; use [`../packages/`](../packages/).
- Product decisions not recorded in [`../docs/`](../docs/).

Relevant docs: [`../docs/architecture.md`](../docs/architecture.md), [`../docs/privacy.md`](../docs/privacy.md), [`../docs/content-licensing.md`](../docs/content-licensing.md).

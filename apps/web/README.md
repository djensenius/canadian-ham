# apps/web

Purpose: future static web app built with Vite, React, TypeScript, and pnpm.

Belongs here:

- Web app source, static assets, service-worker configuration, and web-only tests once scaffolded.
- Web privacy checks specific to browser runtime behaviour.

Must not go here:

- Verbatim ISED source artifacts or generated bank data copied by hand.
- Server-side application backends, accounts, analytics, third-party request code, or remote fonts.
- Apple app or shared engine implementation code.

Relevant docs: [`../../docs/architecture.md`](../../docs/architecture.md), [`../../docs/requirements.md`](../../docs/requirements.md), [`../../docs/privacy.md`](../../docs/privacy.md), [`../../docs/content-licensing.md`](../../docs/content-licensing.md).

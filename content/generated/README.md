# content/generated

Purpose: committed importer output used by app builds and validation.

Belongs here:

- Generated normalized JSON for reviewed bank versions, such as `basic-2025-07-15/` after T-102.
- Source manifests emitted by the importer.

Must not go here:

- Hand-written or hand-edited bank records.
- Verbatim source artifacts; use [`../sources/ised/`](../sources/ised/).
- Lessons, explanations, or app code.

Relevant docs: [`../../docs/architecture.md`](../../docs/architecture.md), [`../../docs/requirements.md`](../../docs/requirements.md), [`../../docs/content-licensing.md`](../../docs/content-licensing.md).

# content/sources

Purpose: private-development source artifacts used by importers and verification scripts.

Belongs here:

- Source subdirectories grouped by provider, such as [`ised/`](ised/).
- Provider-level documentation about preserving byte-identical source files.

Must not go here:

- Normalized JSON output; use [`../generated/`](../generated/).
- Original lessons or explanations.
- Edited or reformatted copies of official artifacts.

Relevant docs: [`../../docs/architecture.md`](../../docs/architecture.md), [`../../docs/exam-facts.md`](../../docs/exam-facts.md), [`../../docs/content-licensing.md`](../../docs/content-licensing.md).

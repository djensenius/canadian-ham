## Diagram descriptions (project accessibility text, not ISED labels)

The diagrams on pages 2–5 have no written labels. The following descriptions give the visible symbols and connections, not answers or added block labels. Arrows run left to right unless noted. Each page repeats the department names, title and authorization statement above and ends with its page number.

## Page 2

- Top diagram: antenna → triangle → circle containing an X → box with a flat-topped band-pass curve → triangle → box with a diode symbol → triangle → loudspeaker. A box containing a sine wave below the X circle has an upward arrow into that circle.
- Middle diagram: antenna → triangle → circle containing an X → box with a flat-topped band-pass curve → triangle → circle containing an X → triangle → loudspeaker. Each X circle has a separate sine-wave box below it with an upward arrow into the circle.
- Bottom diagram: sine-wave box → triangle → triangle → box with a low-pass curve → antenna. A box with an open telegraph-key symbol below the second triangle has an upward arrow into that triangle.

## Page 3

- Top diagram: antenna → triangle → circle containing an X → box with a flat-topped band-pass curve → triangle → box showing an oscillating red wave bounded above and below by horizontal blue lines → box showing a closely spaced wave above a downward arrow and a slower sine wave below → triangle → loudspeaker. A sine-wave box below the X circle has an upward arrow into that circle.
- Second diagram: sine-wave box → triangle → box showing a closely spaced wave and a slower sine wave on the left and an amplitude-varying wave on the right → triangle → box with a low-pass curve → antenna. A microphone below the chain points right to a triangle, whose output turns upward into the wave-combining box.
- Third diagram: sine-wave box → circle containing an X → box with a flat-topped band-pass curve → circle containing an X → triangle → box with a low-pass curve → antenna. A microphone below the first X circle points right to a triangle, whose output turns upward into that circle. A sine-wave box below the second X circle has an upward arrow into it.
- Bottom diagram: microphone → triangle → box showing an irregular blue waveform → sine-wave box → box showing a slower sine wave above a downward arrow and a closely spaced blue wave below → triangle → box with a low-pass curve → antenna.

## Page 4

- Top diagram: circle containing a sine wave → box with a transformer symbol → box with four diodes in a diamond → box with a capacitor symbol, one plate curved → box with a bent-bar diode symbol pointing upward → box with a resistor symbol.
- Middle diagram: three parallel vertical antenna elements mounted across a horizontal boom. The left element is longest, the centre element is shorter, and the right element is shortest. A narrow parallel matching section sits beside the upper half of the centre element, with a connection at its upper end and a feed connection near the boom.
- Bottom diagram: laptop ↔ interface box ↔ radio connected to an antenna. There are two parallel connections between the interface box and the radio: the upper connection is bidirectional, and the lower connection points from the interface box toward the radio.

## Page 5

- Top diagram: a box at upper left has a bidirectional horizontal connection to a radio at upper right and a bidirectional vertical connection to a laptop below it. The laptop also has a bidirectional diagonal connection to the radio. The radio connects to an antenna.
- Bottom diagram: radio → dashed-outline triangle → box with a low-pass curve → analogue meter → box with a meter and knobs → three-position switch. The switch's top and middle contacts connect to separate antennas. Its bottom contact connects to a box with a resistor symbol. The switch arm points to the middle contact.

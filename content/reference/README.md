# content/reference

Purpose: reference material metadata and assets allowed for the current private-development or public-release stage.

Belongs here:

- Metadata describing reference assets, source URLs, labels, checksums, and licensing status.
- Bundled reference assets only when allowed by the current stage in [`../../docs/content-licensing.md`](../../docs/content-licensing.md).

Must not go here:

- Reference PDFs outside the interim private-development policy or public-release gate.
- Recreated ISED diagrams unless written permission explicitly allows derivatives.
- App viewer code.

Relevant docs: [`../../docs/content-licensing.md`](../../docs/content-licensing.md), [`../../docs/exam-facts.md`](../../docs/exam-facts.md), [`../../docs/architecture.md`](../../docs/architecture.md).

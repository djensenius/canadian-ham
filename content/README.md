# content

Purpose: source, generated, and original course content shared by all platforms.

Belongs here:

- Verbatim official source artifacts under [`sources/ised/`](sources/ised/).
- Importer-generated normalized JSON under [`generated/`](generated/).
- Original lessons under [`lessons/`](lessons/), explanations under [`explanations/`](explanations/), and reference metadata/assets under [`reference/`](reference/).

Must not go here:

- Application source code.
- Hand-edited generated bank output.
- Official ISED text mixed into original lesson or explanation prose.

Relevant docs: [`../docs/architecture.md`](../docs/architecture.md), [`../docs/requirements.md`](../docs/requirements.md), [`../docs/content-licensing.md`](../docs/content-licensing.md).
